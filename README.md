# HOOK ARENA · 鉤魂競技場

受經典鉤子競技玩法啟發的原創瀏覽器遊戲原型。寫實風格粉紅豬角色圖、2.5D 畫面、固定斜俯視、5v5–8v8 團隊戰、可單機練習，也可由玩家主持 P2P 對戰，空位由 AI 補上。預設 5v5，優先維持操作流暢度；單機不需帳號或網路，連線對戰需使用網路。

換機或交接給新的 Codex 時，先讀 [AGENTS.md](AGENTS.md) 與 [HANDOFF.md](HANDOFF.md)，確認 checkout 已同步最新 `main`；不要假設舊環境的程序和下載檔會自動同步。

## 下載遊玩

[下載 v0.13 ZIP](https://github.com/tommy-ux-cloud/gpt_game_test/raw/refs/heads/main/downloads/Hook-Arena-v0.13.zip)，先解壓縮，再以最新版 Chrome、Edge 或 Firefox 開啟其中的 `Hook-Arena.html`，不用安裝 Node.js。單機可離線，連線模式仍需網路。

這是已打包的遊戲，與 GitHub「Code → Download ZIP」下載的原始碼不同。聊天室的雲端工作區檔案連結可能無法預覽或下載 HTML，請優先使用上方 GitHub ZIP 連結。

## 開發

需要 Node.js 20 以上版本；不需安裝依賴。使用瀏覽器 Canvas 2D 與本地 PNG，不需要 WebGL 或執行時 CDN。PeerJS 1.5.5 已保存在 `vendor/`，MIT 授權見 [vendor/README.md](vendor/README.md)。

```sh
npm run dev
```

伺服器預設使用 3000 埠，可透過 `PORT` 調整。使用現有 checkout 開發即可。執行 `npm test` 驗證鉤子碰撞、拉人、傷害、重生、河岸邊界與勝負判定。

執行 `npm run build:download` 產生 `dist/Hook-Arena.html` 單檔離線版，可直接用桌面瀏覽器開啟。也可透過 `npm run build:download -- /指定路徑/Hook-Arena.html` 指定輸出位置。

## 玩法

- 滑鼠右鍵點地移動、Q 朝游標出鉤（瞄準角色身體）、S 停止、B 商店、Esc / P 暫停。
- 地圖 3600 × 2250，鏡頭固定跟隨角色，顯示 1200 × 750（全圖面積 1/9）。地面使用約 55° 的正交斜俯視構圖；角色使用八方向透明圖，配合陰影、前後排序和 Canvas 動畫呈現 2.5D。投影保持原本的視野面積；滑鼠輸入會反算成地圖座標。方向鍵、滑鼠邊緣、小地圖均不移動鏡頭；小地圖僅提供全圖資訊。
- 開局可選 5v5、6v6、7v7 或 8v8（預設 5v5），左右兩隊人數相同。單機時左側藍鉤隊包含你與 AI 隊友，右側赤鉤隊全為 AI；連線依房間分隊，空位由 AI 補上，出生位置分散排列；戰況排行按隊分組並可捲動查看所有角色。中央直向河道不可步行，鉤子可穿越。被拉到對岸後可在該半場移動，陣亡後只在自己隊伍的半場重生。
- 開局可自訂隊伍勝利擊殺數（1–9999，預設 30），或選擇無限對戰。暫停後可按「重新設定對局」開始新局。友軍鉤可拉回救援，不造成傷害或給予擊殺獎勵。
- 出去與空鉤回收時都能命中，每次施放最多鉤中一人。鉤頭與瞄準線位於角色胸口高度，與地面走位座標分開；命中以鉤頭範圍與角色碰撞半徑計算，依最早接觸時間選擇目標，並掃描角色在當幀的移動。鉤子回到身上後才開始冷卻，飛行與回收時不能再次出鉤。基礎傷害 55、射程 820、冷卻 2.4 秒、鉤速 650（初始回收速度約 826）、鉤頭半徑 8；基礎最大生命 100、每秒回血 0.5、移速 185。
- 陣亡 3 秒後以目前最大生命重生，獲得 2 秒保護；金錢與升級保留到本局結束。新一局歸零。
- 可從右上角放大競技場、切換音效。購物期間戰鬥仍繼續。

## 粉紅豬角色（v0.12）

依使用者核准的[暗黑角色概念圖](assets/pig-concept.png)製作多方向角色圖，保留粉紅短毛、豬鼻與垂耳、黑上衣橘色旋紋、藍短褲、皮革與舊鐵護甲。藍鉤隊／赤鉤隊分別使用藍／紅鉤頭，血條、小地圖及排行使用相同隊色。

`assets/pig-blue-atlas.png` 和 `assets/pig-red-atlas.png` 各含 4×4 畫格：八個固定朝向、每方向兩個步態。這是圖片式 2.5D；行走使用雙畫格交替及小幅起伏，出鉤／受擊／被拉／倒下使用輕量圖像變形動畫。不是可自由轉動的 3D 模型，也不是完整骨架動作。

頁首「角色展示」直接使用對戰的同一組角色圖。可拖曳或按箭頭切換八方向、切換紅藍鉤頭；對戰中開啟會暫停，關閉後繼續。

圖片成功載入後才可開局；若失敗可重試。圖片隨專案及下載版一起保存，不依賴外部網址。下載 HTML 約 5 MiB，已內嵌兩張 PNG。

## P2P 連線對戰（v0.13 測試版）

1. 所有人開啟相同版本的遊戲。使用 GitHub Pages 或下載 HTML 都可以；連線模式需要網路。
2. 房主可先設定隊伍人數與擊殺目標，再按頁首「連線對戰」→「建立房間」。
3. 將 **8 位房號** 傳給朋友，朋友按「連線對戰」輸入房號加入。
4. 房主按「開始對戰」。真人會平均分到紅藍兩隊，其餘角色由 AI 補上。

採用 PeerJS 免費配對服務和 WebRTC DataChannel：配對服務協助交換連線資訊，房主負責移動、AI、鉤子、傷害、勝負與購物運算，不需自行部署遊戲伺服器。加入者只傳操作，房主送出狀態；房主的電腦效能及上傳頻寬會影響對局。

第一版限開戰前加入。客人離開後 AI 接手，房主可在勝負後回房間再開一場。房主關閉分頁或離開會結束房間，不支援房主轉移。房主分頁在背景時整局暫停；一般選單、說明與角色展示只暫停本人的操作，不會暫停其他人的對戰。

使用公共 STUN 協助直連，**尚未提供 TURN 中繼**；部分公司、校園或路由器網路可能無法直連。免費配對服務也需要可連線，故不保證所有網路都能成功加入。

已用兩個獨立 Chromium、測試用本機配對與 TCP TURN 中繼，驗證真正的 WebRTC 資料通道、角色控制、出鉤／傷害／冷卻、購物、勝負、重賽與斷線。雲端環境限制外部配對及直接 UDP，尚未驗證免費外網服務或跨路由器直連；測試用中繼不包含在正式遊戲設定中，亦未實測 16 位真人的外網負載。

## 金屬鎖鏈（v0.13）

鉤繩改為交錯的金屬鏈節，包含暗面、高光、磨損、局部鏽色及鉤頭接環。去程較緊，空鉤回收時有少量鬆動；所有變化僅為繪圖，不改變鉤頭位置、命中範圍、速度或冷卻。鏈節預先繪製並共用，不需額外圖片下載。

## 靶場練習

開局「遊戲模式」可選 **靶場練習 · 固定靶人**。場上只有玩家與一位敵方靶人，不開啟其他 AI 或勝負判定，隊伍對戰及無限對戰設定保留。

靶人有 **100 萬生命、每秒回血 10 萬**，不自行移動、不攻擊、不購物，但可以正常受到傷害及被鉤回；拉回結束 0.75 秒後自動回到起點。若受到極高傷害倒下，0.5 秒後原位恢復，不給擊殺金錢或連殺。HUD 記錄出鉤、命中次數與累計傷害。

按 **R** 或「重置靶人」可立即讓靶人滿血歸位，取消飛行中的鉤子並重置玩家冷卻。統計保留到新對局開始。

## 連殺與終結獎勵

- 連殺以單條生命計算，無時間限制；本條命第一殺獲得 $1，第二殺及之後每殺獲得 $2。
- 終結至少兩連殺的敵人，額外獲得 **對手連殺數** 的金錢；首殺終結三連殺可得 $1 + $3 = $4，自身已有連殺時則得 $2 + $3 = $5。
- 死亡立即清空連殺，金錢與升級保留。重生後下一殺恢復 $1；新對局重設金錢、升級、隊伍分數及連殺。
- 友軍鉤不造成傷害，不給金錢、不增加或終結連殺。
- 擊殺訊息顯示這次獲得的總額、連殺與終結獎金；排行與自身 HUD 顯示目前連殺。

## 中立商人與升級

左右外側邊線中央各有一位中立商人。兩位都無隊伍限制、無敵且不會被鉤中，也不會擋住鉤子。

靠近商人 230 範圍內才能購買。按 B 或右上角商店可先看數值；距離不足時可點「前往本側商人」自動走近，抵達後會自動開啟商店。點擊可見商人也能前往或交易。被拉到敵方半場後，同樣可使用當地商人。

所有項目每次花費 **1 金錢**，每級小幅累加，畫面顯示目前值、升級後數值與等級：

| 項目 | 每級效果 |
| --- | --- |
| 最大生命 | +5，同時增加 5 目前生命 |
| 回血速度 | +0.1 HP / 秒 |
| 移動速度 | +3 |
| 鉤子頭大小 | 半徑 +0.75，實際碰撞範圍同步增加 |
| 鉤子冷卻 | 縮短 3%，最低 0.8 秒；達上限不再扣款 |
| 鉤子速度 | +25，出去與回收都加快 |
| 鉤子長度 | 射程 +25 |
| 鉤子傷害 | +2，基礎 55，出去與回收命中都適用；友軍仍為零傷害 |

AI 使用相同的連殺、終結獎勵、距離限制與商店價格，有金錢時會前往附近商人升級。已飛出的鉤子保留施放當下的傷害、速度、長度及大小；冷卻在回收完成時採用當時角色的冷卻數值。

目前支援桌面鍵盤與滑鼠的單機 AI 練習及 P2P 連線測試版；尚未加入帳號、裝備或手機觸控操作。角色圖依使用者提供的形象與核准概念圖產生，地圖與繪圖程式為本專案製作，不包含魔獸爭霸素材。

## GitHub Pages 發布

遊戲是純靜態網站，不需要在 GitHub 上執行 Node.js 或安裝依賴。

在儲存庫 **Settings → Pages → Build and deployment** 選擇 **Deploy from a branch**，分支選擇 **main**、目錄選擇 **/ (root)**，然後儲存。等待 Pages 部署成功後，以 Pages 顯示的網址開啟遊戲。

根目錄的 `.nojekyll` 讓 GitHub 直接發布原始靜態檔案。頁面與模組均使用相對路徑，支援 `/gpt_game_test/` 專案網站路徑。後續推送到 `main` 時，GitHub Pages 會重新部署。`server.js` 僅供本機開發，正式遊戲不需要伺服器。
