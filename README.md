# HOOK ARENA · 鉤魂競技場

受經典鉤子競技玩法啟發的原創瀏覽器遊戲原型。俯視角、自由混戰、1 位玩家與 3 位 AI；無外部素材、套件或帳號需求。

## 開發

需要 Node.js 20 以上版本；不需安裝依賴。

```sh
npm run dev
```

伺服器預設使用 3000 埠，可透過 `PORT` 調整。使用現有 checkout 開發即可。執行 `npm test` 驗證鉤子碰撞、拉人、傷害、重生、河岸邊界與勝負判定。

## 玩法

- 滑鼠右鍵點地：自動移動到指定位置；再次右鍵改變目的地，S 停止。河道不可步行，點擊河道或對岸時會走到本側河岸。
- 滑鼠：瞄準；Q：朝游標方向立即出鉤（快速施法）。移動目的地與瞄準方向各自獨立，左鍵不施放技能。
- 肉鉤射程 820、冷卻 2.4 秒，命中造成 55 傷害並將敵人拉回。
- 100 生命，陣亡 3 秒後重生，重生保護 2 秒。
- 率先取得 8 擊殺獲勝；Esc / P 暫停，可重新開局。
- 音效預設關閉，可從競技場右上角開啟。

目前為桌面鍵盤與滑鼠操作的單機 AI 練習版；尚未加入多人連線、帳號、裝備或手機觸控操作。角色、地圖與程式繪圖為本專案原創，不包含魔獸爭霸素材。

## GitHub Pages 發布

遊戲是純靜態網站，不需要在 GitHub 上執行 Node.js 或安裝依賴。

在儲存庫 **Settings → Pages → Build and deployment** 選擇 **Deploy from a branch**，分支選擇 **main**、目錄選擇 **/ (root)**，然後儲存。等待 Pages 部署成功後，以 Pages 顯示的網址開啟遊戲。

根目錄的 `.nojekyll` 讓 GitHub 直接發布原始靜態檔案。頁面與模組均使用相對路徑，支援 `/gpt_game_test/` 專案網站路徑。後續推送到 `main` 時，GitHub Pages 會重新部署。`server.js` 僅供本機開發，正式遊戲不需要伺服器。
